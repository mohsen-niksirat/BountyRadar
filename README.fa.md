اپ ویندوزی محلی برای پیدا کردن **بانتی‌های پولی فریلنسری و متن‌باز** برای **هر** نوع فریلنسر — فرانت‌اند، بک‌اند، موبایل، داده/یادگیری ماشین، دواپس، امنیت، مستندات/نوشتن، طراحی، فول‌استک.

**سایت پیش‌نمایش (استاتیک):** بعد از فعال‌سازی Pages → `https://mohsen-niksirat.github.io/BountyRadar/`

## امکانات

- **۱۰ پروفایل فریلنسری** با امتیازدهی مهارت (skill match)
- **کیفیت پیش‌پرواز** — PR رقیب، تاریخچه merge بیرونی → **مناسب / احتیاط / متوقف**
- **حالت دیده‌بان** — اسکن دوره‌ای + نوتیفیکیشن ویندوز (اجرای اول بی‌صدا مبنا ثبت می‌کند)
- **رابط وب مدرن** — فیلتر چندتایی، مرتب‌سازی، صفحه‌بندی، کارت/جدول، نمودار روند امتیاز
- **چندزبانه واقعی** — انگلیسی / فارسی با راست‌به‌چپ (کلید زبان در هدر)
- **بدون API پولی** — فقط کتابخانه‌های استاندارد پایتون ۳

## اجرا

**دوبار روی `Bounty Radar.bat` کلیک کن** → مرورگر روی `http://127.0.0.1:8765/` باز می‌شود

```bash
git clone https://github.com/mohsen-niksirat/BountyRadar.git
cd BountyRadar
python bounty_radar.py                 # رابط وب (پیش‌فرض)
python bounty_radar.py --tk            # پنجره کلاسیک Tkinter
python bounty_radar.py --scan --profile frontend
python bounty_radar.py --watch 15
python bounty_radar.py --notify-test
python test_bounty_radar.py            # تست‌های آفلاین
```

## امتیازدهی

```
score = مبلغ ÷ (۱ + تعداد claim)
        × تازگی         (≤۷ روز: ۱.۶ · ≤۳۰ روز: ۱.۲۵ · ≥۱۲۰ روز: ۰.۴۵)
        × کیفیت مخزن    (★≥۱۰۰۰: ۱.۱۵ · فعال: ۱.۱ · آرشیو: ۰.۲)
        × تطابق مهارت   (کلیدواژه پروفایل، تا ۱.۴۵)
        × پیش‌پرواز     (مناسب ۱.۲ · احتیاط ۰.۷ · متوقف ۰.۲۵)
        × جریمه‌ها      (>۶۰ کامنت: ۰.۶ · بدون ستاره: ۰.۷)
```

## منابع داده

| منبع | چه می‌دهد |
|------|-----------|
| صفحات سازمانی الگورا | مبلغ واقعی + تعداد claim |
| جست‌وجوی گیت‌هاب | برچسب‌ها، `/bounty $`، کامنت ربات Opire |
| REST گیت‌هاب | ستاره / فعالیت برای کاندیدهای برتر |

برای سهمیه بیشتر، **توکن گیت‌هاب** (بدون scope) را در تنظیمات بگذار.

## حالت دیده‌بان

1. **دیده‌بان** را روشن کن  
2. اولین اسکن = مبنای بی‌صدا  
3. هر N دقیقه: موارد جدید سبز می‌شوند + یک نوتیفیکیشن  
4. `seen.json` بین اجراها یادش می‌ماند
