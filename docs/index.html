Why it works

Built for quality, not noise

Most bounty labels on GitHub are spam or leftovers. The radar ranks what is actually worth your time.

🎯

Explainable score

Amount ÷ competition × freshness × skill match × preflight. Every multiplier is shown.

🛡

Preflight quality

Competing PRs, external-merge history, issue state → GO / CAUTION / STOP.

⚡

Watch mode

Rescan every N minutes. New bounties highlight + Windows toast. Silent baseline first.

🧠

Skill matching

Docs, design, mobile, ML — non-code freelancers rank too via keyword boosts.

🧹

Fake filter

Blocks farms, $0 tags, absurd amounts, airdrop/wallet/private-key scams.

📦

Zero install

Python 3 stdlib only. Double-click the .bat, browser opens the local UI.

Get started

Run it locally in 4 steps

GitHub Pages hosts this static site. The radar itself runs on your machine.

Clone

Get the repo on your Windows machine.

Double-click

Open Bounty Radar.bat.

Pick a profile

Frontend, Docs, Design… then Scan.

Add a GitHub token for higher rate limits.

cd BountyRadar
# Windows: double-click Bounty Radar.bat
python bounty_radar.py
python bounty_radar.py --scan --profile frontend
python test_bounty_radar.py
