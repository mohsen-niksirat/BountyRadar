Get started

Run it on Windows

GitHub Pages only hosts this page. The radar itself is a local app.

git clone https://github.com/mohsen-niksirat/BountyRadar.git
cd BountyRadar

# Option A — from source (Python 3 required)
python bounty_radar.py
# opens http://127.0.0.1:8765/

# Option B — standalone .exe (no Python on target PC)
pip install -r requirements-build.txt
build.bat
# → dist\BountyRadar\BountyRadar.exe

python test_bounty_radar.py   # offline tests
