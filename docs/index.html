Built for quality, not noise

Most “bounty” labels on GitHub are spam or leftovers. The radar ranks what is actually worth your time.

🎯

Explainable score

Amount ÷ competition × freshness × skill match × preflight. Every multiplier is shown in the Why column.

🛡

Preflight quality

Competing PRs, external-merge history, issue state — turned into GO / CAUTION / STOP before you commit time.

⚡

Watch mode

Rescan every N minutes. New bounties get a green highlight and a Windows toast. First scan is a silent baseline.

🧠

Skill matching

Docs, design, mobile, ML — non-code freelancers rank too via keyword boosts, not just language filters.

🧹

Fake-bounty filter

Blocks known farms, $0 tags, absurd amounts, airdrop/wallet/private-key scams.

📦

Zero install stack

Python 3 + stdlib only. Double-click the .bat, browser opens the local UI. No pip, no Electron.

Run it locally

GitHub Pages can only host this static site. The radar itself runs on your machine.

Clone

Get the repo on your Windows machine.

Double-click

Open Bounty Radar.bat.

Pick a profile

Frontend, Docs, Design… then Scan.

Optional token

Add a GitHub token for higher rate limits.

git clone https://github.com/mohsen-niksirat/BountyRadar.git
cd BountyRadar
# Windows: double-click Bounty Radar.bat
python bounty_radar.py --web   # or just: python bounty_radar.py
python bounty_radar.py --scan --profile frontend
python test_bounty_radar.py   # offline tests
Keyboard in the local UI: S scan · W watch · / search · E CSV · Esc close
